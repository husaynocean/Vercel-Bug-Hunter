A High it couldn't have memorised · Canto
cNOTE has 18 decimals. The code assumed 8.
function withdrawCarry(uint256 _amount) { max = (cNote.balanceOf(this) * rate) / 1e28 - totalSupply(); ... }
The math always underflows, so the owner's interest is locked forever. No attacker needed.
Then it proves it
$ forge test [PASS] bug reproduced - / 1e28 - totalSupply(); + / 1e18 - totalSupply(); $ forge test [FAIL] fix verified
The test passes on the buggy code and fails once the fix is in. That's the proof.
