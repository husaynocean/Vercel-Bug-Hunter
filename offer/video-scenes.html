The problem with AI bug finders
They flood you with false alarms.
Judges reject them. Teams ignore them. Your reputation pays for it.
So this one has one rule: no failing test, no report.
The pipeline
1Load only the code in scope
2Scan with Slither + Semgrep
3AI reviews every function
4Write a test that breaks the code
5Report only what the test proves
A real High it caught · PoolTogether
One line. A partial fee claim wiped the whole fee balance.
function claimYieldFeeShares(uint256 _shares) { ... yieldFeeBalance -= _yieldFeeBalance; _mint(msg.sender, _shares); }
Claim part of your fees and the rest is gone for good. No attacker needed.
Then it proves it
$ forge test [PASS] bug reproduced - yieldFeeBalance -= _yieldFeeBalance; + yieldFeeBalance -= _shares; $ forge test [FAIL] fix verified
The test passes on the buggy code and fails once the fix is in. That's the proof.
